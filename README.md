# TryHackMe Cybersecurity Journey

A record of my hands-on cybersecurity learning through TryHackMe rooms, CTF challenges, and practical labs.

## Portfolio contents

- [Room progress tracker](progress-tracker.md) — status of every room recovered from my ChatGPT learning history.
- [Room history](rooms/README.md) — room-by-room notes, progress, and evidence confidence.
- [Learning notes](learning-notes/README.md) — concepts and tools encountered during labs.

## Progress and accuracy

This portfolio distinguishes **completed**, **in progress**, **attempted**, and **mentioned / status unknown** rooms. A flag or answer discussed in a chat is not treated as proof that a room was completed. Entries marked as uncertain will be updated only after checking the TryHackMe room progress or accepted answers.

This is a learning log, not an official TryHackMe transcript. Room flags and answer keys are intentionally not published here; writeups should focus on methodology, concepts, and lessons learned.

## Topics covered so far

- SQL injection and file-upload risks
- Security monitoring and Sigma
- Hardware and firmware security
- MQTT / IoT security
- Attack surface reduction and defence in depth
- OPSEC and general security fundamentals

## Updating this portfolio

New rooms will be added with their actual status, key skills, tools used, and lessons learned. Incomplete or unverified work will remain clearly labelled rather than being presented as completed.
