## Worked-On Rooms & Study Notes

The separate [worked-on rooms guide](rooms/worked-on-rooms.md) collects meaningful work from earlier lab sessions, including partial progress and unresolved investigations. It also includes answer strings recovered from prior discussions, with confidence notes so readers can distinguish useful leads from verified answers.

## How to use these notes

- Start with the room name and status before using any recovered answer.
- Treat historical progress percentages as snapshots, not current progress.
- Recheck answers marked **unverified**, **disputed**, or **needs validation** against the actual room task.
- Use methodology notes as learning references, not as a substitute for understanding the lab.

## Responsible disclosure

This repository is intended for learning and future reference. Challenge flags, passwords, credentials, API keys, access tokens, and other sensitive access details are not published. Only work that can be responsibly documented is included.

## Accuracy & completion policy

- A room is marked completed only after explicit 100% completion confirmation.
- Partial or attempted rooms remain separate from the completed list.
- Guessed, rejected, or uncertain answers are not presented as confirmed solutions.
