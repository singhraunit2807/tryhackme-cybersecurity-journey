# Learning Notes

This folder will contain concept-focused notes from completed and ongoing TryHackMe labs.

Recovered themes from prior sessions include:

- **Web security:** IDOR, unrestricted file upload, file extension validation, file renaming, malware scanning, SQL injection, second-order SQL injection.
- **Security monitoring:** Sigma rules, event logs, process and scheduled-task investigation.
- **Hardware and embedded security:** logic analysers, firmware inspection, UART / serial communication concepts.
- **IoT:** MQTT and camera/device security.
- **Defensive security:** attack surface reduction, defence in depth, password vault practices.
- **Fundamentals:** OSI model, OPSEC, DNS records, HTTP headers, ICMP/ping, IPv4, MAC addresses, ARP, subnet masks, Shodan, common web-server ports, Caesar cipher, encryption, CIA triad, and incident response.

Only add commands, screenshots, or technical claims after they are checked against the actual lab notes.
